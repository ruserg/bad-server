# Проектная работа "WebLarek. Плохой сервер.", спринт 17

## Подготовка к работе

1. Склонировать репозиторий.
2. Запустить docker:

```bash
docker compose up -d
```

3. Наполнить базу данных — см. [README.md](.dump/README.md).
4. Перейти по адресу [http://localhost/](http://localhost/) — на странице должны быть продукты.
5. На странице [http://localhost/login/](http://localhost/login/) можно авторизоваться.
6. Админка находится по адресу [http://localhost/admin/](http://localhost/admin/).
